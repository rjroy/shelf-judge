## Final-gate failure history and fix

The first exact Bun 1.4.0 aggregate run had one failure, not in `logger.test.ts`: `packages/web/tests/daemon-transport.test.ts:133` expected an `AbortError` but received `socket hang up`. `packages/web/lib/daemon.ts` removed its error listener before destroying the aborted socket. The production fix preserves cleanup through destruction; the subsequent exact Bun 1.4.0 aggregate result is 2,769 pass, 1 skip, 0 fail. A stale, unlistened Playwright fixture Unix socket can separately cause the web server's `EADDRINUSE`; it is test-runtime residue rather than an assertion failure and was removed before the successful browser re-run.

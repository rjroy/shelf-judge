## Epic-Wide Signal Disposition

| Prior or candidate signal                                                      | Disposition  | Current behavior                                                                                                                                                                                                       |
| ------------------------------------------------------------------------------ | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Full-fitness Tournament divergence                                             | Repaired     | Compares normalized, non-provisional Tournament preference with fitness recomposed only from rated non-Tournament axes; Tournament contribution and vetoes are excluded                                                |
| Ownership concentration as axis evidence                                       | Retired      | A trigger can emit a visible retired record explaining why frequency alone does not establish preference                                                                                                               |
| High factual variance as axis evidence                                         | Retired      | A trigger can emit a visible retired record explaining why spread alone does not establish preference                                                                                                                  |
| Divergence-repair axis suggestion                                              | Reclassified | Reports only a comparator-backed directional attribute association and frames it as an observational question, not an instruction to create an axis                                                                    |
| Collection centroid and two-standard-deviation outlier rule                    | Replaced     | Uses deterministic distance to the two nearest complete owned-game factual neighbors, with sample, coverage, distance, and multi-driver gates                                                                          |
| `lone-wolf`, `category-orphan`, and `high-fitness` outlier classifications     | Retired      | Reports factual neighborhood distance and concrete dimension drivers; optional fitness is separately measured context and never a detection input                                                                      |
| Free-form narration claims                                                     | Rejected     | The model selects reported insight references only; the server copies canonical observation and interpretation text and validates every insight/game reference                                                         |
| Insufficient, missing-comparator, weak-effect, or confounded insight candidate | Abstained    | Emits explicit insufficient or suppressed records when the contract has a meaningful failed state; a completed adequate evaluation with no notable result returns `[]`                                                 |
| Count-derived confidence tiers                                                 | Rejected     | No calibrated confidence model exists, so current producers publish `confidence: null`; algorithm-v5 caches carrying count-derived tiers remain historical evidence and all pre-v7 caches are discarded and recomputed |
